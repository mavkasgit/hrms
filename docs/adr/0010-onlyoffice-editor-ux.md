# ADR-0010: Тихая загрузка редактора OnlyOffice и подавление его попапов

Дата: 2026-08-11. Статус: принято.

## Контекст

Редактор OnlyOffice показывал мгновенно сообщение «Загрузка редактора… отключите
блокировщик рекламы» при каждом открытии — ложная тревога при нормальной (но
долгой) загрузке. Плюс Document Server 9.x сам показывал два навязчивых попапа:
«Введите имя для совместной работы» (из-за отсутствия `editorConfig.user`)
и «Новое. Многостраничный просмотр» ("what's new" features tip 8.2+).

## Решение

1. **Двухуровневый таймаут загрузки** (фронт, `OrderEditor.tsx`):
   0–20с ничего; 20с — плавный мягкий хинт «Загрузка редактора…»; готовность
   редактора — плавное исчезновение хинта; 60с — жёсткая ошибка (как раньше).
   Жёсткая ошибка остаётся для терминальных случаев: скрипт-фейл `api.js`,
   отсутствие `DocsAPI`, событие `onError`. Хинт — последнее предложение про
   блокировщик, а не первое, что видит пользователь.
2. **`editorConfig.user` всегда** (бэкенд, `build_config`): `id` = username,
   `name` = full_name (или username, если ФИО пусто). Окно ввода имени больше
   не показывается; `name` никогда не пустой.
3. **`customization.features.featuresTips: false`** (бэкенд, `build_config`):
   "what's new" попап отключается. Параметр существует в 8.2+; версия не
   гейтится, так как зафиксирована `onlyoffice/documentserver:9.4.0` во всех
   compose-окружениях и CI.

## Почему

Сообщение о блокировщике появлялось мгновенно при каждой загрузке, хотя
20-секундный таймаут должен быть запасным, а не приветствием. Оба попапа
управляются конфигом редактора и устраняются на источнике, без
localStorage-костылей и «скрыть навсегда» хаков. `user` решает и диалог имени,
и запись анонимного соавтора в шапке OnlyOffice.

## Последствия

- Конфиг-эндпоинты (8 шт.) получают `current_user: CurrentUser` вместо строки,
  чтобы достать `full_name`.
- Старый жёсткий фейл на 20-й секунде убирается — редактор не уничтожается
  при медленной загрузке.
- На Document Server старше 8.2 `featuresTips` безвредно игнорируется:
  попап останется, ничего не сломается.
