## What to build

Пользователь заполняет форму «Создать приказ» (сотрудник, тип приказа, дата, номер, дополнительные поля) и может закрыть вкладку или перезагрузить страницу в любой момент — заполненное не теряется.

При следующем открытии страницы приказов показывается уведомление «Найдено несохранённое заполнение формы приказа» с действиями «Восстановить» / «Не сейчас» / «Удалить». Форма автоматически не заполняется — восстановление только по явному решению пользователя. При восстановлении данные перевалидируются: сотрудник загружается заново по id, тип приказа — из актуального списка активных типов.

Используется один слот на пользователя/браузер. При начале нового заполнения, когда уже есть сохранённое, запрашивается подтверждение перезаписи.

## Acceptance criteria

- [ ] Заполнение формы автоматически сохраняется (debounced) и переживает перезагрузку/закрытие вкладки
- [ ] На странице приказов показывается уведомление с действиями «Восстановить» / «Не сейчас» / «Удалить»
- [ ] «Восстановить» заполняет форму и перевалидирует данные; «Не сейчас» прячет уведомление до следующего раза; «Удалить» очищает сохранённое
- [ ] При наличии сохранённого заполнения начало нового заполнения запрашивает подтверждение перезаписи
- [ ] E2E-тест: заполнить форму → перезагрузить страницу → восстановить через уведомление

## Blocked by

None — can start immediately.
