## What to build

На странице приказов появляется раздел «Черновики» со списком всех существующих черновиков — видны все, без фильтра по владельцу. По каждому черновику отображаются: тип приказа, сотрудник, дата, номер, время создания, статус.

Каждый черновик можно продолжить редактировать в редакторе, сохранить как приказ или удалить (удаление — с подтверждением). Черновик больше не «пропадает»: он виден и управляем, пока пользователь сам не решит его сохранить или удалить.

## Acceptance criteria

- [ ] API-список черновиков возвращает все черновики с отображаемыми данными из метаданных
- [ ] В разделе «Черновики» отображаются тип приказа, сотрудник, дата, номер, время создания, статус
- [ ] «Продолжить редактирование» открывает редактор черновика
- [ ] «Сохранить» превращает черновик в приказ
- [ ] «Удалить» удаляет черновик после подтверждения
- [ ] E2E-тест: создать черновик → увидеть его в списке → удалить
