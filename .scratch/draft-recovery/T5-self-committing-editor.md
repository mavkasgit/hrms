## What to build

Приказ можно сохранить, даже если страница приказов, с которой открыли редактор, уже закрыта или перезагружена. Окно редактора после принудительного сохранения документа само создаёт приказ из серверных метаданных черновика и закрывается только после подтверждения сервера. Зависимость от cross-window сигнала в родительскую вкладку устраняется.

## Acceptance criteria

- [ ] Сохранение приказа из редактора работает без открытой родительской страницы приказов
- [ ] Окно редактора закрывается только после успешного ответа сервера
- [ ] После этой возможности редактор не дублирует сигнал сохранения родительской странице
- [ ] Повторный/параллельный коммит не создаёт второй приказ (тихо, без ошибки у пользователя)
- [ ] E2E-тест: открыть редактор, закрыть родительскую страницу, сохранить приказ из редактора

## Blocked by
